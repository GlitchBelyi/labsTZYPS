**Що спрацювало:** клон, збірка Maven, запуск усіх юніт-тестів, формування звітів у `target/surefire-reports/`. Червоні тести відповідають заявленим Issues.

**Що довелося з'ясовувати:**
1. Інструкція запуску лежить у `qa-eduportal/README.md`, а в `docs/sprint4/` немає README команди (W4).

4. UI-05 у режимі `-DexcludedGroups=none` залежить від доступності demo і локатора помилки (W1).

Середовище аудитора відрізняється від описаного в документах: JDK 21 замість 17 (README і протокол Чупая), Maven 3.9.11 замість 3.10.0 (протокол) і Windows 11 у протоколі Чупая замість Linux. Збірка й тести пройшли без змін коду, бо `pom.xml` компілює з `maven.compiler.release=17`; результат прогону збігається з протоколом Чупая, тож розбіжність версій на нього не вплинула (див. W5).
