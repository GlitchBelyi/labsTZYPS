# Питання замовнику Q1 і Q3 (до надсилання погодити)

Тема: ЕдуПортал, модуль v1.0.0: уточнення SRS 1.1 для тестування (BL-80, BL-50/BL-60)

Добрий день!
Під час автоматизації тестів Спринту 4 нам потрібні дві відповіді. До них тестуємо за найрозумнішим трактуванням і позначаємо тест як «інтерпретація».

**Q1. BL-80, формат результату `violations`.** SRS 1.1 описує повідомлення українською («Невірний код зарахування» тощо), а README модуля — коди KEY, PERIOD, CAPACITY, PREREQUISITE. Який формат є правильним? Якщо українські рядки, розбіжність ми оформимо як дефект (Issue #38); якщо коди, виправимо SRS.

**Q3. BL-50/BL-60, порядок округлення.** Чи округлюється частковий бал питання (наприклад, 2/3 = 0,6667 → 0,67) перед підсумком, чи округлюється лише остаточний відсоток? Для 2 правильних із 3 це дає 67,0 або 66,7. Зараз модуль повертає 67,0 (Issue #37).
