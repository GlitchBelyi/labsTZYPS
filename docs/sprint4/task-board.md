## Правила Git

- Гілка: `feature/<номер>-<назва>`; коміт починається з `[UT-BLxx]`, `[UI-xx]`, `[BUG-NN]` або `[DOC-S4]`.
- Злиття у main — лише через PR після рецензії колеги; кожен комітить під власним логіном.
- Червоний тест через дефект модуля не вимикається (`@Disabled` заборонено), а посилається на Issue.
- Код у `src/main/java` не змінюємо.
