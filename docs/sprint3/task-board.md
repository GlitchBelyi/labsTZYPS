## Ризики і домовленості

- Demo скидається щогодини. Кожен кейс незалежний, а потрібні курси й діяльності створює передумова. Дати в кейсах задаємо відносно дня виконання.
- Навантажувальні перевірки, масові запити, зміна паролів спільних облікових записів і введення реальних даних заборонені (етика 5.4). Порушення дає 0 за командну частину.
- Кожен failed має власний Bug ID. Звіт без середовища й дати не приймається.
