# BPMN-моделі — Спринт 1, «ЕдуПортал»

## Інструмент

Моделі побудовані в **diagrams.net** (він же draw.io), нотація — **BPMN 2.0**,
фігури з вбудованої бібліотеки "BPMN" (More Shapes → BPMN).

## Файли

| Файл | Модель |
|---|---|
| `01_enrollment.drawio` / `.png` | Зарахування на курс |
| `02_assignment.drawio` / `.png` | Здача завдання та оцінювання |
| `03_quiz.drawio` / `.png` | Проходження тесту |
| `04_course_creation.drawio` / `.png` | Створення курсу |

`.drawio` — редаговане джерело (відкривати для внесення змін).
`.png` — експортований знімок для швидкого перегляду без відкриття редактора (у README, в презентації на демо тощо).

## Як відкрити `.drawio`

1. Зайти на **https://app.diagrams.net** у браузері (не подвійним кліком по файлу).
2. File → Open from → Device → обрати потрібний `.drawio`.
3. Якщо після відкриття видно не все — View → Reset View (`Ctrl+Shift+H`), щоб вписати всю діаграму в екран.

## Позначення, використані в моделях

- **Пул** — суцільна рамка з назвою учасника процесу (Студент / ЕдуПортал).
- **Доріжка** — горизонтальна смуга всередині пулу, одна на роль (Система, Викладач, Менеджер курсів тощо).
- Суцільна стрілка — потік керування (тільки в межах одного пулу).
- Пунктирна стрілка — потік повідомлень (між пулами) або асоціація до об'єкта/сховища даних (без стрілки на кінці).
- Ромб — шлюз: помаранчевий з написом-питанням = XOR (виключне АБО за даними); зелений з "+" = AND (паралельний); подвійне коло з п'ятикутником = шлюз за подіями.
- Тонке коло — початкова/проміжна подія; коло з товстою червоною межею — кінцева подія.
