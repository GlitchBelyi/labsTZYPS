## 3. Розбіжності SRS 1.1 і v1, які треба тріажувати (задача 11, КТ)

За пробним запуском v1 крім шести явних помилок розходиться зі SRS 1.1 ще в чотирьох місцях. Сюди не відносимо питання, позначені «потребує підтвердження замовником»: тріаж вирішує, це дефект модуля чи питання замовнику.

1. **BL-72:** `keyMatches` кидає NullPointerException, коли слово курсу не задано; SRS 1.1 вимагає false (рядок С-11, потребує підтвердження).
2. **BL-76:** `hasCapacity` не кидає виняток для capacity ≤ 0 і enrolled < 0 (рядок С-11, потребує підтвердження).
3. **BL-60:** `score` ігнорує id відповіді, якого немає в ключі; SRS 1.1 (дефект №21) вимагає IllegalArgumentException.
4. **BL-80:** `violations` повертає коди `KEY`, `PERIOD`, `CAPACITY`, `PREREQUISITE`, а SRS 1.1 (дефект №23) вимагає українські рядки.
