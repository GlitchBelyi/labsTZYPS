## TC-004: Валідація наявності базових курсів на головній сторінці

* **Опис:** Перевірка того, що на головній сторінці публічної пісочниці Moodle безпосередньо відображаються обов'язкові навчальні курси.
* **URL:** `https://sandbox.moodledemo.net/`
* **Покроковий сценарій:**
  1. **Відкриття сторінки:** Виконати команду `open` для переходу на головну сторінку ресурсу.
  2. **Перевірка другого курсу:** 
     * **Дія:** Пошук елемента за текстовим посиланням.
     * **Локатор:** `By.linkText("My second course")`
     * **Очікування/Перевірка:** Використовується неявна перевірка розміру списку знайдених елементів (`assert(elements.size() > 0)`), що підтверджує присутність курсу в DOM.
  3. **Перевірка першого курсу:** 
     * **Дія:** Пошук елемента за текстовим посиланням.
     * **Локатор:** `By.linkText("My first course")`
     * **Очікування/Перевірка:** Підтвердження наявності елемента на сторінці (`assert(elements.size() > 0)`).
* **Очікуваний результат:** Обидва курси ("My first course" та "My second course") успішно знайдено на головній сторінці.

## TC-005: Валідація глобального пошуку при введенні неіснуючого запиту

* **Опис:** Перевірка коректності обробки пошукового запиту системою Moodle у випадку, коли за введеним значенням немає жодних збігів.
* **URL:** `https://sandbox.moodledemo.net/search/index.php`
* **Покроковий сценарій:**
  1. **Відкриття сторінки пошуку:** Виконати команду `open` для прямого переходу до панелі глобального пошуку.
  2. **Очікування елемента (Explicit Wait):** 
     * **Дія:** Застосування `WebDriverWait` з таймаутом 10 секунд для стабільного завантаження динамічних компонентів.
     * **Локатор поля вводу:** `css=input[id^='searchinput']`
     * **Умова очікування:** `ExpectedConditions.presenceOfElementLocated` (очікування появи поля в DOM-дереві).
  3. **Введення пошукового запиту:** 
     * **Дія:** Заповнення поля пошуку тестовим неіснуючим значенням `T3-Zzzq-9999`.
     * **Механізм:** Взаємодія через виконання сценарію або події вводу у поле з динамічним ідентифікатором.
  4. **Виконання пошуку (Enter):**
     * **Дія:** Імітація натискання клавіші `Enter` (або події `KeyboardEvent`) для надсилання пошукового запиту.
  5. **Перевірка результату:**
     * **Дія:** Сканування текстового вмісту сторінки на наявність сповіщення про відсутність результатів.
     * **Очікування/Перевірка:** Пошук слова `Результат відсутній` у тілі документа (`document.body.innerText.includes('Результат відсутній')`).
* **Очікуваний результат:** Система успішно обробляє запит і виводить на екран текст-повідомлення про те, що результати за запитом `T3-Zzzq-9999` відсутні.

## TC-017 / UI-04: Склад форми входу (вимога GUI-10)

**Тест-метод:** `LoginFormUiTest.loginFormHasExpectedElements`, `LoginFormUiTest.loginFormTextsMatchSrs`
**Передумови:** Відкрито сторінку входу `https://sandbox.moodledemo.net/login/index.php`. Не авторизований.
**Кроки:**
1. Перевірити наявність поля імені (`#username`).
2. Перевірити поле пароля (`#password`), атрибут `type="password"`.
3. Перевірити наявність кнопки входу (`#loginbtn`).
4. Перевірити наявність кнопки «Увійти як гість» (`#loginguestbtn`).
5. Перевірити наявність посилання «Забули пароль?» (`a[href*='forgot_password']`).
6. Перевірити наявність перемикача показу пароля (`.toggle-sensitive-btn`).
7. Перевірити наявність перемикача мови (`a[data-bs-toggle='dropdown'][aria-haspopup='true']`).
8. Перевірити тексти написів на сторінці.

**Очікуваний результат:** 
Кроки 1-7: усі елементи присутні на сторінці, локатори унікальні. 
Крок 8: тексти відповідають SRS 1.1 (очікувано червоний через Issue #2, оскільки на demo інтерфейс англійською).
