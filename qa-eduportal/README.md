# Модуль бізнес-логіки «ЕдуПортал» — версія 1.0.0 (Спринт 4)

Java-модуль продукту П6 «ЕдуПортал» (система дистанційного навчання) для спринта 4 «Автоматизація: JUnit 5 і Selenium WebDriver». Модуль реалізує правила розділу 5 «Вимоги до бізнес-логіки» специфікації `SRS_06_ЕдуПортал.html` (вимоги `BL-10`…`BL-80`) і не має зовнішніх залежностей.

## 1. Вимоги до середовища

* **JDK:** 17 (Temurin)
* **Maven:** 3.9 або вище
* **Бібліотеки:** JUnit 5.10, Selenium 4.21 (підтягуються з `pom.xml`)
* **Браузер:** Google Chrome (для UI-тестів). Драйвер встановлюється автоматично через Selenium Manager.

## 2. Як зібрати і запустити тести

Усі команди виконуються з кореневої папки проєкту (де лежить `pom.xml`).

**Запуск лише швидких юніт-тестів (без браузера):**

```bash
mvn clean test
```

**Запуск усіх тестів, включаючи UI-тести (Selenium WebDriver):**

```bash
mvn test -DexcludedGroups=none
```

**Запуск конкретного тестового класу:**

```bash
mvn test -DexcludedGroups=none -Dtest=LoginFormUiTest
```

Звіти про виконання Surefire зберігаються у папці `target/surefire-reports/`.

## 3. Структура проєкту та тестів

* `src/main/java/ua/kpi/tzyapz/eduportal/` — модуль бізнес-логіки v1 (3 класи + record-и).
* `src/test/java/ua/kpi/tzyapz/eduportal/` — юніт-тести JUnit 5.
* `src/test/java/ua/kpi/tzyapz/eduportal/ui/` — UI-тести Selenium WebDriver (успадковують `BaseUiTest`).
* `selenium-ide/` — записи сценаріїв у Selenium IDE (`.side`).
* `docs/` — матриця покриття, протокол запуску (Surefire).

## 6. Реалізовані правила (бізнес-логіка)

* **BL-10.** Сума ваг елементів дорівнює 100, бали 0..100 — інакше `IllegalArgumentException`; підсумок = Σ бал × вага / 100, округлення до 2 знаків (`HALF_UP`).
* **BL-20.** Шкала ECTS: A ≥ 95; B 85–94; C 75–84; D 65–74; E 60–64; Fx 35–59; F < 35 (межі трактуються як «від включно, до не включно»: B — 85 ≤ total < 95 тощо).
* **BL-30.** Штраф за запізнення: −10 % від балу за кожен день, максимум −50 %; округлення до 2 знаків.
* **BL-40.** Одна правильна відповідь: 1 бал, якщо обрано саме її, інакше 0; без відповіді — 0.
* **BL-50.** Кілька правильних: частка обраних правильних мінус частка обраних неправильних, не менше 0.
* **BL-60.** Підсумок спроби = сума балів / кількість питань у ключі × 100, округлення до 1 знака.
* **BL-70.** Зарахування можливе, коли одночасно: кодове слово збігається (з урахуванням регістру); дата у межах періоду зарахування включно; зараховано менше за місткість; передумовний курс складено з ≥ 60 балами.
* **BL-80.** `violations(...)` повертає коди порушень у порядку перевірки: `KEY`, `PERIOD`, `CAPACITY`, `PREREQUISITE` (див. Issue #38 щодо формату результатів).

Дати — `java.time.LocalDate`; десяткові значення — `double` з округленням `BigDecimal` `HALF_UP`.
